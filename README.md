# H-Guard
AI-powered real-time human violence detection system using YOLOv8s and computer vision for intelligent surveillance. SHE GUARD detects violent activities from CCTV/video feeds, triggers instant alerts, and enhances public safety through automated AI-based monitoring and threat detection.


## 📌 Overview

H GUARD is an intelligent surveillance system that detects violent activities such as fights, assaults, and aggressive behavior in real time using YOLOv8s and OpenCV. The system processes live video feeds, identifies potential threats, and instantly triggers alerts through alarms and email notifications.

The project aims to reduce dependency on manual surveillance monitoring while improving response time, security, and public safety in both public and private environments.

## 📂 Dataset

The model was trained using the RWF-2000 dataset containing:

- 1000 violent video clips
- 1000 non-violent video clips

### Dataset Details
- Video Format: `.avi`
- Duration: 3–10 seconds
- Frame Rate: 25–30 FPS

Dataset Source:
https://www.kaggle.com/datasets/mohamedmustafa/real-life-violence-situations-dataset

## 🧠 Model Architecture

The system uses YOLOv8s for real-time violence detection from surveillance footage.

### Pipeline
- Video Frame Extraction
- Image Preprocessing
- YOLOv8s Detection
- Violence Classification
- Alert Generation

### Performance
- Test Accuracy: 80%
- Real-time detection capability
- Optimized for low-latency surveillance monitoring

---

## ⚙️ System Workflow

1. Live CCTV/video feed is captured
2. Frames are extracted and preprocessed
3. YOLOv8s analyzes human activities
4. Violent actions are detected in real time
5. Alarm and email alerts are triggered
6. User monitors activity through the dashboard
